# カテゴリのドロップ候補表示

Issue #894。既存のキーボード操作・ライブ通知（#895）と reduced-motion 対応（#896）を維持し、カテゴリの候補表示を共有する。

| 状態        | 表示                 | 意味                                             |
| ----------- | -------------------- | ------------------------------------------------ |
| idle        | 通常                 | ドラッグしていない。終了・取消後もこの状態へ戻る |
| source      | 半透明               | ドラッグ中のカテゴリ自身                         |
| available   | テーマ色の破線       | 現在のドラッグで選択できる候補                   |
| over        | テーマ色の実線と背景 | 現在選択している候補                             |
| unavailable | 灰色の点線           | 現在のドラッグでは選択できない場所               |

outline を内側へ描画し、候補・選択中への切り替えで border 幅や padding を変えない。ドラッグに伴う既存の折りたたみ・並べ替え transform は維持する。

Domain の親カテゴリ・子カテゴリは、それぞれ既存の DndContext 内でカテゴリ1件を並べ替える。URL の別カテゴリへの移動は追加しない。ドロップ後は既存のプレビューと確定・取消操作を使い、保存失敗時はプレビューを保持してエラーを通知する。

Custom はカテゴリ1件の同一プロジェクト内の並べ替え、または URL 1件の移動を扱う。カテゴリ、空カテゴリ、未分類の候補表示に、collision / keyboard と同じ候補判定を使う。別プロジェクトのカテゴリはカテゴリ並べ替えの対象外。URL の別プロジェクトへの移動は、既存どおり移動先の未分類へ入る。保存処理と成功・失敗通知は既存ハンドラに委譲する。

タッチではカテゴリのハンドルだけに `touch-action: none` を設定する。ブラウザのスクロール開始に伴う `pointercancel` でドラッグが取り消されることを防ぎ、ハンドル以外からの通常スクロールは維持する。

保存形式・拡張権限・センサー・移動可能な範囲は変更しない。

## 回帰確認

- `useDropTargetFeedback.test.tsx`: 候補判定、対象外、ドラッグ元、選択中、終了後の解除、無効な古い hover、未登録・disabled な対象。
- `SortableCategorySection.test.tsx`、`CustomProjectCategory*.test.tsx`、`ProjectCardUncategorizedArea.test.tsx`: 実際の表示要素への状態反映と hover 時の寸法維持。
- `e2e/helpers/keyboard-dnd.ts`: Domain 親・子／Custom の候補と選択中の実際の線種、Escape、確定、IndexedDB、再読み込み。Chrome と Firefox の既存シナリオで共有する。
- `e2e/category-drop-feedback.extension.spec.ts`: マウスでの有効・対象外表示、候補の寸法、取消、自動スクロール、実タッチ入力でのカテゴリ1件の並べ替え・保存・再読み込み。
