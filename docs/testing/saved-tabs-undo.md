# 保存済みタブの Undo

[Issue #922](https://github.com/haruto-yamada1/TABBIN/issues/922) の操作監査です。削除確認と既存スナップショット復元の方針は [ADR 0001](../adr/0001-saved-tabs-deletion-confirmation-policy.md) と [#472](https://github.com/haruto-yamada1/TABBIN/issues/472) を参照してください。

| 操作                                                                           | 完了通知と元に戻す入口                                                                                                                  | 元に戻した後のデータ                                                                                       |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| ブラウザのボタン、メニュー、ショートカットからタブを保存                       | ブラウザ通知で保存結果を表示。元タブを閉じる場合があるため、保存だけを巻き戻すボタンは設けない                                          | 保存済みタブ一覧から対象を開き直せる。保存データの削除には一覧の Undo が使える                             |
| 右クリックやページ内リンクキャプチャでリンクを保存                             | 既存のブラウザ通知またはページ内の保存結果を表示。保存を繰り返すと既存 URL の日時や所属が変わる経路があり、保存通知からの Undo は対象外 | 保存データの確認・削除は保存済みタブ一覧で行う                                                             |
| Domain / Custom の単一・一括削除、Analytics の削除、保存データを開いた後の削除 | 通知の「元に戻す」。一括操作は既存の通知単位で復元                                                                                      | 各削除経路の既存スナップショットで URL と対象の所属・カテゴリを復元                                        |
| Custom の別プロジェクトへ保存済み URL を移動                                   | マウス・キーボードで確定後、通知の「元に戻す」。同一プロジェクト内の並べ替えやカテゴリ編集は、確定前のキャンセルが入口                  | 元プロジェクトのカテゴリ、メモ、表示順と URL への参照を復元。移動先に既に同じ URL があれば、その所属を維持 |
| 「定期実行」で期限切れタブを「すべて復元」                                     | 完了通知の「元に戻す」。個別の復元と確認付き完全削除は従来どおり                                                                        | 今回復元した変更を戻し、元の復元期限で保管一覧に戻す。復元前から保存済みだった URL や所属を維持            |
| バックアップから選択したデータを一括復元                                       | Options の「復元ポイント」から確認付きで元データを復元                                                                                  | インポート直前の復元ポイントに従う。復元ポイントの有効期限は Options に表示                                |

Custom の削除、プロジェクト間移動、期限切れタブの一括復元は、Undo ボタン付き通知を通常10秒間表示します。Domain と Analytics のスナップショット復元は従来の表示時間を使います。従来のスナップショット通知は、ポインターを合わせるとタイマーが一時停止します。移動と一括復元の10秒は画面を移動しても延長されません。ページを閉じたり再読み込みしたりすると、そのページの Undo は使えなくなります。

移動と期限切れタブの一括復元では、既存の IndexedDB トランザクションが返すリビジョンに対して逆方向の変更を一括適用します。別画面からデータが更新された場合や、元の保管期限が切れた場合はエラーを表示し、更新後のデータを保持します。通知の操作は拡張機能内で完結します。

## 回帰検証

- `IndexedDbSavedTabsSessionService.test.ts` は復元する差分、リビジョン競合、保管期限と期限切れデータの扱いを検証。
- `cross-mode-deletion.extension.spec.ts` は一括削除から5秒後の Undo と両モードでの再読み込みを検証。
- Chromium と Firefox のキーボード D&D はプロジェクト間移動の Undo と IndexedDB の所属・メモを検証。
- `expired-tabs-alarm-lifecycle.extension.spec.ts` は Chromium で一括復元と Undo を実行し、保管一覧へ戻った URL を再度復元できることを検証。
