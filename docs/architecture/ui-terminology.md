# UI 文言の用語集（glossary）

画面文言（辞書 `src/features/i18n/*Messages.*.ts` と Academy の文言）を追加・変更
するときの標準表現。新規文言のレビュー観点として使う。日本語の揺れを防ぐことが
目的で、英語は原則として既存の統一済み表現に合わせる。

## 標準表現

| 概念                       | 標準（ja）                                   | 標準（en）                   | 使わない表現・備考                                                                                           |
| -------------------------- | -------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 取り消しできない操作の警告 | この操作は元に戻せません                     | This action cannot be undone | 「取り消せません」「削除すると元に戻せません」は使わない。Undo ボタンの文言「元に戻す」と対応させる          |
| Undo（操作の取り消し）     | 元に戻す／元に戻せます／元に戻せませんでした | Undo / can be undone         | 「取り消す」は Undo の意味では使わない。「取り消し」はドラッグや入力などのキャンセル（cancel）用途に限る     |
| 分類の単位                 | カテゴリ（親カテゴリ／子カテゴリ）           | category                     | 「ジャンル」は使わない（AI 分析の表示も含む）                                                                |
| データの復旧               | 復元                                         | Restore                      | 「復元」はバックアップや Import の復旧ポイントからのデータ復旧専用。保存タブを開く意味では使わない           |
| 保存タブを開く             | 開く                                         | Open                         | Academy の案内でも「開く」に統一する（「タブを復元」と書かない）                                             |
| 実体の削除                 | 削除                                         | Delete                       | 保存データや会話など、対象そのものが消える操作                                                               |
| コレクションから外す       | 取り除く／外す                               | Remove                       | カテゴリからのドメイン解除、検索履歴や除外パターンの除去など、対象そのものは消えない操作は「削除」と書かない |

## レビュー観点

- 破壊的操作の確認文は「〜しますか？この操作は元に戻せません。」の形に揃える。
- 新しいボタンや aria-label を作るときは、その操作が「削除」（実体が消える）か
  「取り除く」（所属や一覧から外れるだけ）かを確認してから語を選ぶ。
- 辞書の文言を変更したら、対応するテストの期待値も同じ PR で追随させる。
- 過去のリリースノート（`changelogItems`）は履歴として書き換えない。
