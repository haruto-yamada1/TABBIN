# i18n のデフォルト言語とフォールバック

TABBIN のデフォルト言語は英語 (`en`) とする。共通定数
`src/constants/language.ts` の `DEFAULT_LANGUAGE` を、Chrome / Firefox の
`manifest.default_locale`、アプリの未対応ロケール・未翻訳キーのフォールバック、
Firefox 成果物の検証で使う。

拡張機能の `src/locales/en.json` / `ja.json` は、manifest の
`__MSG_*__` に使う名前・説明などを管理する。ブラウザが対応するロケールを選び、
未対応ロケールでは `default_locale: 'en'` を使う。
アプリ画面の翻訳は `src/features/i18n/messages.ts` が管理し、拡張機能の辞書とは
別の責務を持つ。両方ともデフォルトを `en` に揃える。

言語設定の初期値は `system`。`chrome.i18n.getUILanguage()` を優先し、利用できない
場合は `navigator.language` を参照する。`system` の解決規則は次のとおり。

| UI ロケール                                      | アプリ言語 |
| ------------------------------------------------ | ---------- |
| `ja`、`ja-JP`                                    | `ja`       |
| `en`、`en-US`、`en-GB`                           | `en`       |
| 未対応 (`fr`、`ko`、`zh` など)、空文字、取得不可 | `en`       |

明示的な `ja` / `en` 設定は UI ロケールより優先する。既存の言語設定は移行・上書き
しない。選択した言語に翻訳キーがない場合は英語辞書、呼び出し側の fallback、キー自体の
順に解決する。翻訳品質と辞書の key / placeholder parity は別の検証対象とする。

`src/features/i18n/lib/language.test.ts` でロケール解決とフォールバックを、
`tools/scripts/firefox-artifact-contract.test.ts` と `verify:firefox-artifact` で
英語のデフォルトと `en` / `ja` 辞書の同梱を検証する。
