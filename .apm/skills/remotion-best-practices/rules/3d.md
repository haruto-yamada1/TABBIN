# Remotion で Three.js / React Three Fiber を使う

React Three Fiber と Three.js の best practice に従ってください。  
追加で守る Remotion 固有ルールは次のとおりです:

## 前提条件

`@remotion/three` パッケージを先にインストールします。  
未インストールの場合は次のコマンドを使用:

```bash
npx remotion add @remotion/three # npm プロジェクト
bunx remotion add @remotion/three # bun プロジェクト
yarn remotion add @remotion/three # yarn プロジェクト
pnpm exec remotion add @remotion/three # pnpm プロジェクト
```

## 利用: ThreeCanvas

3D コンテンツは **必ず** `<ThreeCanvas>` で包み、適切な lighting を含めます。  
`<ThreeCanvas>` には **必ず** `width` / `height` prop が必要です。

```tsx
import { ThreeCanvas } from "@remotion/three";
import { useVideoConfig } from "remotion";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <ambientLight intensity={0.4} />
  <directionalLight position={[5, 5, 5]} intensity={0.8} />
  <mesh>
    <sphereGeometry args={[1, 32, 32]} />
    <meshStandardMaterial color="red" />
  </mesh>
</ThreeCanvas>;
```

## `useCurrentFrame()` 以外で駆動するアニメーション禁止

shader、model などは **単独では** アニメーションしてはいけません。  
`useCurrentFrame()` で駆動しないアニメーションは禁止です。  
そうしないと render 時にちらつきます。

`@react-three/fiber` の `useFrame()` は **禁止** です。

## `useCurrentFrame()` でアニメーション

`useCurrentFrame()` でアニメーションを駆動します。

```tsx
const frame = useCurrentFrame();
const rotationY = frame * 0.02;

<mesh rotation={[0, rotationY, 0]}>
  <boxGeometry args={[2, 2, 2]} />
  <meshStandardMaterial color="#4a9eff" />
</mesh>;
```

## 利用: `<ThreeCanvas>` 内の `<Sequence>`

`<ThreeCanvas>` 内の `<Sequence>` は `layout` prop を **必ず** `none` にします。

```tsx
import { Sequence } from "remotion";
import { ThreeCanvas } from "@remotion/three";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <Sequence layout="none">
    <mesh>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#4a9eff" />
    </mesh>
  </Sequence>
</ThreeCanvas>;
```
